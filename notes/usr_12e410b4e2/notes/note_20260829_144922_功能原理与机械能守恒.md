## 一句话

把保守力的功改记成势能变化后，动能定理升级成：外力功 + 非保守内力功 = 机械能增量。

## 核心公式

$$W_{\text{外}}+W_{\text{非保守内力}}=\Delta E_{\text{机械}},\qquad
\text{只有保守力做功时 } E_k+E_p=\text{恒量}.$$

## 我的理解

- 重力、弹簧弹力、万有引力是保守力：做功只看初末位置，与路径无关 → 才有“势能”可记。
- 滑块—弹簧—斜面综合题的标准清单：初机械能 = 末机械能 + 摩擦生热清单，一行解决。
- “守恒条件”要背准确：外力和非保守内力都不做功（或代数和为零）。

## 易错点

- 把滑动摩擦力对两个物体分别做的功漏算一半，生热要用相对路程。
- 弹簧“原长状态”弹性势能为零，压缩和拉伸都要按形变量平方算。
