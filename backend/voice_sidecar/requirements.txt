# 默认不安装：unidecode (GPL-2.0+)、pykakasi (GPLv3+)、num2words
# (LGPL)、完整 unidic 词典（约 1 GB 磁盘）和 eng_to_ipa（本方案未确认
# 许可依据）。pykakasi/num2words 虽被上游非中文模块在导入期引用，但由

# 但 melo/text/cleaner.py 在 import 期加载全部语言模块，因此必须装以下
# 「导入期需要、中文合成不执行」的宽松许可包：mecab-python3/unidic-lite
# （日语 MeCab 模块级初始化需要；unidic-lite 仅约 15 MB、BSD/MIT 数据，
# 不是 1 GB 的完整 unidic）、anyascii、jamo（韩语导入期需要，MIT/BSD）。
# 发布 sidecar venv 时仍应按实际安装文件生成 SBOM；复用旧环境不能仅凭
# 本 requirements 文件推断其许可证集合。

#   pip install torch torchaudio --index-url https://download.pytorch.org/whl/cpu
# 直接 `pip install -r` 会从 PyPI 拉 CUDA 版 torch（约 3-4 GB）。
#
